# 秘匿のものの置き方

結（yui）は**秘匿の印を持ちません。**
秘匿のものは**別のファイルに分けて**ください。

## なぜ印を持たないのか

「印を付けた点は、明示しない限り本文を出さない」という作りは考えましたが、入れません。

★**それは漏れを防がないからです。**

| 印を付けても | |
|---|---|
| ファイルの中 | **平文で入っています**（`strings` で出ます） |
| `探す` | **当たります**（索引は本文から作ります） |
| デーモン | 開いたファイルの中身を返します |

防げるのは「うっかり画面に出ること」だけで、**それを「秘匿」と呼ぶと、
守られていると読まれます。**守られていないのに守られていると読む方が、
守る仕組みが無いことより危ないので、印そのものを作りません。

## どう分けるか

```
共有のもの      記録.yui        ← デーモンで配る・持ち出す・人に見せる
秘匿のもの      秘.yui          ← 自分だけ。置き場の権限で守る
```

- 線はファイルをまたげません。共有の側には**在り処だけ**を書きます
  （例: `作る (人:甲 {鍵: "秘.yui の (鍵:甲の口座)"})`）
- 秘匿の側は**デーモンに開かせません**。デーモンは開いた 1 つのファイルを配ります
- ★**置き場を 700 にするか、ファイルを 600 にしてください。**
  結は 644 で作るので（`umask` が効きます）、**何もしなければ同じ機械の他の人から読めます**

```sh
mkdir -p ~/.local/share/yui && chmod 700 ~/.local/share/yui   # 置き場ごと
chmod 600 ~/.local/share/yui/秘.yui                          # またはファイルごと
```

★**置き場ごとの方が確かです。**詰め直すは作業用のファイル（`<パス>.詰`）を置き場に作るので、
**その一瞬を指定で守れるのは置き場の権限だけ**です
（作業用の方にも元の権限を付けていますが、置き場が開いていれば名前だけは見えます）

## ★結がやること・やらないこと

実測（2026-11-08・ext4・umask 022）に基づきます。

| | |
|---|---|
| 新しいファイル | **644 で作ります**（`umask` が効きます）。狭めたいなら自分で `chmod 600` |
| 持ち主が狭めた権限 | ★**詰め直しても広げません**（この版から。前は 644 に戻していました） |
| `消す` | **本文はファイルに残ります。**取り消しの記録を足すだけです |
| `詰め直す` | ファイルからは落ちます。★**ディスクの上から消す手段は結にはありません** |
| `<パス>.錠` | 644 で作ります。中身は名乗り（名前・機械名・pid）です。本文は入りません |

### 土台で違うこと

- **Windows**: 権限は**置き場から継がれます。**元のファイルに個別に付けた許可は、
  詰め直すと消えます（別のファイルになるため）。結はここを触りません
- **WSL2 の /mnt の下**: `chmod` は**成功を返して効きません**（実測: 777 のまま）。
  Windows から見えるところに秘匿のものを置かないでください
- **macOS**: ★**ホームは既定で 700 ではなく 750 でした**（`drwxr-x---`、グループは `staff`）。
  ★これは**使っている人の実測で、こちらでは測っていません**（2026-11-08・1 台だけ）。
  その台で守られていたのは、`staff` の実質の所属が 1 人だけだったことと、
  **置き場を 700 にしていたこと**の 2 つでした。
  ★**人のアカウントを足すと、ホームの 750 を通って入れます。**「ホームに置けば安全」は成り立ちません
- **wasm**: 置き場の権限は、埋め込んだ先の作りによります。
  ★**NODERAWFS では効きました**（600 → 600、640 → 640）。
  ★これは**埋め込んで使っている人の実測で、こちらでは測っていません**
  （2026-11-08・Linux の node・ext4）。★**同じ手順を直す前の版に当てて
  600 → 644 を再現しています**（陽性対照）。
  Windows の node（NTFS）では 666 → 666 で、**mode が実質「読み取り専用かどうか」しか持たない**ため
  振る舞いは変わりません（同じ人の実測）

## うっかり秘匿のものを書いたときの手当て

```
1. yui 秘.yui '消す (点の名前)'     ← ファイルにはまだ残っています
2. yui 秘.yui '詰め直す'            ← ここで落ちます
3. ★共有の側に書いていたなら、配った先も確かめてください
```

★**3 を忘れないでください。**デーモンで配ったもの・コミットしたもの・
送ったものは、こちらで消しても戻りません。

## 測っていないこと

- 暗号化（案 D）は入れていません。要るなら**結の外**で掛けてください
