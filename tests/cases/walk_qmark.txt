# 辿る で [?] と書いたときの手がかり
#
# ★点の側の (?何) は「何でもよい」の印だが、線の側に変数は無い。
#   [?] は「種類が『?』という名前の線」を探すので 0 件になる。
#   そのまま黙ると、打った人は「つながりが無い」と読む。実際に利用者が踏んだ。
#   種類を問わないなら [] と書く。

> 結ぶ (人:田中)-[返信]->(人:佐藤)
(人:田中)-[返信]->(人:佐藤)
+ 作りました（端の点も 2 つ 作りました）

# [] なら種類を問わないので、ちゃんと出る
> 辿る (人:田中)-[]->(?相手)
(人:田中)-[返信]->(人:佐藤)
+ 1 件

# ★[?] は 0 件。そのとき手がかりを添える
> 辿る (人:田中)-[?]->(?相手)
+ 0 件（「[?]」は種類が「?」の線です。種類を問わないなら [] です）

# ★[?種類] のように名前を付けても同じ（線の側に変数は無い）
> 辿る (人:田中)-[?種類]->(?相手)
+ 0 件（「[?種類]」は種類が「?種類」の線です。種類を問わないなら [] です）

# 向きが逆でも同じ
> 辿る (人:佐藤)<-[?]-(?相手)
+ 0 件（「[?]」は種類が「?」の線です。種類を問わないなら [] です）

# ★「?」で始まらない種類で 0 件のときは、手がかりを足さない
#   （「そんな種類の線は無い」が答えなので、[] を薦めるのは筋違い）
> 辿る (人:田中)-[そんな種類]->(?相手)
+ 0 件

# ★当たっているときは手がかりを出さない
> 辿る (人:田中)-[返信]->(?相手)
(人:田中)-[返信]->(人:佐藤)
+ 1 件
