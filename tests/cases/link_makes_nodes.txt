# 結ぶ が端の点を作ったら、そう言う
#   結ぶ は点が無ければ作る言葉です（README に書いてあります）が、
#   出力には出ていませんでした。
#   ★流し込みで名前を打ち間違えると、属性の無い点が静かに増えます。
#     実際に 2 人の利用者が踏んでいます。数えれば分かるものを、
#     数えなくても分かるようにします。

# 両方 無いとき
> 結ぶ (案件:結)-[担当]->(人:田中)
(案件:結)-[担当]->(人:田中)
+ 作りました（端の点も 2 つ 作りました）

# 片方だけ無いとき
> 結ぶ (案件:結)-[発注]->(会社:A)
(案件:結)-[発注]->(会社:A)
+ 作りました（端の点も 1 つ 作りました）

# 両方 あるとき —— 何も言わない
> 結ぶ (案件:結)-[関係]->(人:田中)
(案件:結)-[関係]->(人:田中)
+ 作りました

# ★作る で先に作っておけば、言われない（これが「打ち間違えていない」形）
> 作る (人:佐藤)
(人:佐藤)
+ 作りました
> 結ぶ (案件:結)-[担当]->(人:佐藤)
(案件:結)-[担当]->(人:佐藤)
+ 作りました

# 同じ線をもう一度 結ぶと、更新になる（端の点は増えない）
> 結ぶ (案件:結)-[担当]->(人:田中 {役職: "部長"})
(案件:結)-[担当]->(人:田中)
+ 変わりません

# 作られた点は属性を持たない。これで「打ち間違えて増えた点」を見つけられる
> 一覧 (会社:) 名前だけ
(会社:A)
+ 1 件
> 見る (会社:A)
(会社:A)
  <-[発注]-(案件:結)
+ 1 件

> 終わる
