# 索引の枠の境目
#   索引は「2〜3 文字の並び」ごとに、それを持つ文書の番号を並べます。
#   ★2 件までは枠の中に直に持ち、3 件目で外に出します（yui.c の GramSlot の★）。
#     その移り目が不具合の隠れる場所なので、1・2・3・4 件を直に見ます。
#   ★このケースだけでは守りきれません。陽性対照を 2 通り 取って測った結果です。
#     (1) 枠の外に出すときに 2 件目を落とす
#         → このケースの比較で捕まる（3 箇所 NG）。-DYUI_SELFCHECK なら
#           「自己検査に失敗: 索引 2 件 / 全件走査 3 件」で、より早く止まる
#     (2) 枠の中を 1 件にして、移り目だけずらす
#         → ★このケースの比較では捕まらない（61 件 すべて通る）。
#           ASan だけが捕まえる（枠の外を読む）
#     つまり「答えが違う」形は比較で、「枠の外を読む」形は sanitizer で捕まります。
#     ここを触るときは make test-san まで通してください。
