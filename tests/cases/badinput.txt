# 通らない文は、どこが駄目かを言って止まります

> しらない言葉
! 知らない言葉です: しらない言葉（「手引き」で一覧を出せます）
> 結ぶ (a)-(b)
! 文法エラー: 線の種類は [ ] で囲みます（ここ: (b)）
> 結ぶ (a)-[x](b)
! 文法エラー: ] のあとに - か -> が必要です（ここ: (b)）
> 結ぶ (a)-[x]->
! 文法エラー: 点は ( で始めます（文の終わりで止まりました）
> 結ぶ (a)
! 文法エラー: 線は -[ か <-[ で始めます（文の終わりで止まりました）
> 消す (人:佐藤)-[取引]-(人:田中)
! 消す には向きが必要です（-> か <-）
> 作る
! 文法エラー: 点は ( で始めます（文の終わりで止まりました）
> 作る (
! 文法エラー: ラベルか名前が必要です（文の終わりで止まりました）
> 作る (人:田中 {役職: "閉じない)
! 文法エラー: 文字列が閉じていません（文の終わりで止まりました）
> 探す
! 文法エラー: 探す文字を書いてください（例: 探す "既読"）（文の終わりで止まりました）
> 辿る
! 文法エラー: 点は ( で始めます（文の終わりで止まりました）
# ★一覧 も括弧が要ります。
#   古い版は省けて、そのとき 0 件 を返していました（ゼロで埋めた形がどの点にも
#   当たらないためで、意図した振る舞いではありません）。
#   「データが 0 件」と「書き方を間違えた」が同じ見た目になるので、断ります。
#   すべてを出したいときは 一覧 () と書けるので、言い方は失われていません。
> 一覧
! 文法エラー: 一覧 には点の形が必要です（すべてなら 一覧 ()）（文の終わりで止まりました）
# すべてを出す言い方は、今までどおり
> 一覧 ()
+ 0 件
> 見る
! 文法エラー: 点は ( で始めます（文の終わりで止まりました）
